# Music Albums Data Pipeline

## 📌 Project Overview
This project demonstrates a beginner-friendly data pipeline built using Python, MySQL, and Excel. 
The goal is to ingest a messy CSV dataset, clean and transform it using Python, store it in a SQL database, 
and export the final results for analysis in Excel.

## 🛠 Technologies Used
- Python (Pandas, SQLAlchemy)
- Jupyter Notebook
- MySQL
- Excel

## 🔄 Data Pipeline Workflow
1. Load raw CSV data into Python
2. Perform data cleaning and transformation
3. Save cleaned data
4. Load data into a MySQL database
5. Run SQL queries for analysis
6. Export final results to Excel

## 🚀 How to Run the Project
1. Clone the repository
2. Install required Python packages
3. Run `data_pipeline.ipynb`
4. Execute SQL scripts in MySQL Workbench
5. Open Excel file for analysis
